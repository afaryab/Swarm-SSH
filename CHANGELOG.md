# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Initial release of Swarm-SSH
- Docker image with SSH client and Docker CLI
- Interactive menu to select and SSH into containers
- Support for Docker Swarm and standalone Docker mode
- Automatic discovery of neighboring containers
- GitHub Actions workflow for automated builds and releases
- Multi-platform support (amd64, arm64)
- Comprehensive documentation
- Example docker-compose files
- Target container setup guide
- Contributing guidelines
- MIT License

### Features
- 🚀 Interactive container selection menu
- 🔐 SSH key management and mounting
- 🐳 Docker Swarm and standalone mode detection
- 🌐 Traefik compatibility
- 📦 Lightweight Alpine-based image
- 🔄 Automated CI/CD pipeline
